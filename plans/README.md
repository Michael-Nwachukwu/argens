## Findings considered and rejected

(Recorded so future audits don't re-litigate.)

- **".env committed to git"** — false. `apps/api/.env` exists locally but is gitignored; `git ls-files` tracks only `.env.example` and history contains no `.env` commits. Standard practice, not a finding.
- **Single shared `ADMIN_SECRET`, no RBAC** — documented V1 decision in a code comment at the top of `routes/admin.ts`. Revisit at team-scale, not now.
- **Response envelope asymmetry** (`{data}` vs `{error, code}`) — matches the CLAUDE.md API spec exactly; intentional.
- **CORS `*` on SKILL.md / provider skill.md endpoints** — intentionally public agent-onboarding surface, per CLAUDE.md.
- **Marketplace approval executes when price dropped below approved cost** — user-favorable, by design.
- **In-memory PIN-attempt rate limiting** — fine for the current single-instance deployment; the code already comments the Redis migration path. Revisit when scaling out.
- **Next.js 15 / React 19 migration** — real but low leverage now: high regression risk against two 1,300+ line client components with zero tests. Reconsider after 001 lands and the web app has any test coverage.
- **GET /approve/:token returns transaction details for expired/consumed tokens** — low severity (the token is itself the bearer credential and only ever emailed to the account owner); acceptable.
- **Prisma dev query logging** — dev-environment only; no production exposure evidenced.
